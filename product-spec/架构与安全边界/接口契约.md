# 接口契约

所有 JSON 错误响应统一格式为 `{ "error": "message" }`；列表接口始终返回 JSON 数组（不返回 `null`）；ID 为不透明字符串，时间戳为 Unix 秒。

## 1. 业务规则（当前生效）

### 1.1 管理接口（`/api/admin/*`）

仅在主监听端口（HTTPS，或前置反向代理后的本地监听）挂载，全部要求请求头 `Authorization: Bearer <ADMIN_TOKEN>`：

- `GET /api/admin/health`：返回 `{ "ok": true }`，供后台登录态校验。
- `GET /api/admin/nodes`：返回 `model.Node[]`，端点敏感凭据（`password`、`username`、`uuid`、`public_key`、`short_id`）全部脱敏置空。
- `PATCH /api/admin/nodes/:id`：请求体 `{ "name": "...", "enabled": true }`（两字段必填），更新节点展示名称或启停状态；停用节点仍可上报心跳，但立即从所有订阅输出中剔除。
- `DELETE /api/admin/nodes/:id`：返回 `204`，永久吊销该节点 Token 并从所有订阅选择中移除。
- `GET /api/admin/subscriptions`：返回 `model.Subscription[]`，由主密钥解密 `token_enc` 后直接拼装返回 `url` 与可选 `http_url`，支持管理员在后台随时反复查看与复制订阅链接。
- `POST /api/admin/subscriptions`：请求体 `{ "name": "...", "node_ids": ["..."], "protocols": ["hysteria2", "vless"], "routes": { "claude": { "custom": true, "node_ids": ["..."] }, "chatgpt": { ... }, "google": { ... } }, "enabled": true }`，返回 `201` 及 `{ "subscription": Subscription, "url": "<PUBLIC_URL>/sub/<token>", "http_url": "<HTTP_SUB_PUBLIC_URL>/sub/<token>" }`（配置了 `HTTP_SUB_PUBLIC_URL` 时返回 `http_url`）。
- `PUT /api/admin/subscriptions/:id`：同上请求体，原地更新订阅节点/协议/专属分流选择并返回最新 `Subscription`（不轮换订阅 Token，已有链接下次刷新即生效）。
- `POST /api/admin/subscriptions/:id/rotate`：重置订阅 Token（加密更新 `token_enc`），使旧链接立即失效并返回新 `url` / `http_url`。
- `DELETE /api/admin/subscriptions/:id`：返回 `204`，吊销订阅链接（不影响客户端此前已下载缓存的节点密码）。
- `GET /api/admin/subscriptions/:id/preview`：返回完整渲染后的 Clash YAML 文本（含明文客户端连接凭据，严禁写入日志）。

### 1.2 节点 Agent 接口（`/api/agent/*`）

仅在主监听端口挂载，全部使用 Bearer 鉴权：

- `POST /api/agent/register`：持 `ENROLL_TOKEN` 提交 `model.RegisterRequest`，成功返回 `201` `{ "token": "<node_token>" }`；已存在的节点 ID 返回 `409` 拒绝覆盖。
- `POST /api/agent/heartbeat`：持专属节点 Token 提交 `model.HeartbeatRequest`，返回 `200` `{ "ok": true }`。进程启动后的首拍心跳及 `config_hash` 变化时附带完整 `endpoints`，常规心跳省略 `endpoints` 以减少秘密传输；管理端绝不根据请求源 IP 推断节点对外地址。

### 1.3 公共与只读 HTTP 订阅接口

- `GET /healthz`：返回 `{ "ok": true }`。
- `GET /api/public/meta`：返回 `{ "ca_cert_available": true|false }`，供前端登录页探测是否配置了私有根 CA 证书下载。
- `GET /ca.crt`：配置了可选环境变量 `TLS_CA_FILE` 时返回公开 X.509 根证书（启动时强校验 PEM 仅含公开 `CERTIFICATE` 块，严禁包含任何私钥；未配置时返回 `404`），供纯 IP 自签 HTTPS 部署下管理员导入系统信任库以消除浏览器“不安全”警告并启用原生密码管理器。
- `GET /sub/:token`：免登录凭 capability token 实时查询当前数据库选择并动态渲染 mihomo YAML（响应头携带 `Cache-Control: no-store`、`profile-update-interval: 1`、`profile-title: base64:<订阅名>` 及无内层双引号的 RFC 5987 `Content-Disposition: attachment; filename*=UTF-8''<订阅名>`，供 Clash Verge / Stash / FlClash 自动识别订阅名称）；停用或无效 token 返回 `404`。
- **可选双端口订阅监听**：成对设置环境变量 `HTTP_SUB_LISTEN` 与 `HTTP_SUB_PUBLIC_URL` 时，管理端额外启动独立只读 HTTP Server，仅注册 `/healthz` 与 `/sub/:token`，解决纯 IP 自签 HTTPS 环境下 Clash 客户端无法一键导入订阅的问题。

## 2. 跨端代码锚点

- **请求与响应模型**：`internal/model/types.go`
- **主路由与只读订阅路由组装**：`internal/manager/server.go`（`NewHandler`、`NewSubscriptionHandler`）
- **SQLite 持久化与 `token_enc` 加解密**：`internal/manager/store.go`
- **前端 API 调用与订阅弹窗/列表展示**：`web/src/api.ts`、`web/src/types.ts`、`web/src/App.tsx`

## 3. 模块红线

- 独立 HTTP 订阅端口（`NewSubscriptionHandler`）严禁挂载任何 `/api/admin/*`、`/api/agent/*` 或静态后台页面。
- 节点收到心跳 `401`（Token 已被管理员吊销）时必须保留原状态告警，严禁回退使用 `ENROLL_TOKEN` 自动重新注册绕过吊销。
