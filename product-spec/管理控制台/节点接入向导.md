# 节点接入向导

## 1. 业务规则（当前生效）

- **自动探测与可编辑动态模板**：管理后台提供独立的「节点接入指南」页面，登录后自动请求 `GET /api/admin/onboarding` 预填本管理端对外地址（若后端 `PUBLIC_URL` 为回环地址则优先采用当前浏览器访问的公网 Origin）、`ENROLL_TOKEN`、私有根证书 `ca.crt` PEM 状态与内容、默认 GitHub 仓库及运行版本，并根据现有节点列表自动推荐不冲突的下一个节点名称（如 `node-03`）。所有活动参数均提供表单输入框，用户修改任意字段时实时替换全套操作步骤与导出文本。
- **全场景覆盖（对齐节点安装系列技能）**：
  1. **方案 A（`--adopt-existing` 存量内核无感收编）**：默认推荐模式，只读导入既有 `hysteria.service` / `xray.service`，支持按需修改非默认配置文件路径与 systemd unit 名。
  2. **方案 B（纯新机器全套部署）**：包含系统 `fq + bbr` 开启、官方固定版本 Hysteria2 与 Xray 下载与 SHA-256 强核验、以及 Agent 子进程统一托管初始化。
  3. **场景 C（`add-manager` 多管理端接入）**：为已运行 `proxy-server` 的存量节点追加当前管理端并发上报。
- **全链路步骤闭环**：页面依次生成目标主机只读环境探测、（纯新机）BBR 与双核心准备、（私有 CA 启用时）`/etc/proxy-server/manager-ca.crt` 信任链部署、`install.sh` 或 `add-manager` 注册执行、`systemd` 开机自启与 `Wants=`/`After=` 启动顺序及无 `polkitd` 10 次退避自愈核验、以及云防火墙与日后 `update`/`.previous` 回退速查。
- **人机双模阅读与 Copy Markdown**：
  - 支持在「分步操作视图（适合人工逐条复制命令）」与「Markdown 源码视图（适合发送给 AI Agent 或归档）」之间切换。
  - 提供两个独立的复制动作：**复制完整 Markdown（含 `ENROLL_TOKEN`，内置非交互 SSH `SSH_ASKPASS + ssh -T` 防卡死与凭据零泄漏红线，可直接发给 Agent 自动执行）** 与 **复制脱敏 Markdown（使用 `<YOUR_ENROLL_TOKEN>` 占位符，适合公开分享或文档留存）**；界面默认对准入令牌掩码展示。
- **与仓库安装技能双向强同步**：本页面步骤模板与 `skills/install-proxy-server/SKILL.md`、`skills/proxy-cluster-ops/SKILL.md` 保持双向同步，任一方调整安装参数、自启规则或排障范式时必须同步更新另一方。

## 2. 跨端代码锚点

- **向导默认参数接口**：`internal/manager/server.go`（`GET /api/admin/onboarding`）
- **向导步骤与 Agent Markdown 模板引擎**：`web/src/onboarding.ts`
- **前端向导界面与状态绑定**：`web/src/App.tsx`（`OnboardingGuide`）、`web/src/types.ts`
- **对应操作技能文档**：`skills/install-proxy-server/SKILL.md`、`skills/proxy-cluster-ops/SKILL.md`
- **同步门禁脚本**：`scripts/check-context.sh`（`CTX-006`）

## 3. 模块红线

- 生成的命令严禁将 `ENROLL_TOKEN` 或 `GITHUB_TOKEN` 拼入命令行明文参数（如 `--enroll-token <secret>`），必须通过环境变量或受限 `0600` 临时文件传递。
- 严禁在生成的节点命令中关闭管理端 TLS 证书校验；纯 IP / 私有 CA 管理端必须通过写入公开 `ca.crt` 并传入 `--ca-file` 完成严格证书验证。
